# 📊 03-observability (Supervision & Télémétrie)

Ce niveau centralise la configuration des outils d'observabilité et de supervision :
- Ressources d'API Zabbix (Host Groups, Assignations de templates, Webhooks)
- Alerting & Dashboards (Prometheus, Grafana, Alertmanager)
- Canaux de notification (Discord, Slack)

## Dépendances
- Nécessite le réseau (`01-core-network/`) et les instances hôtes (`02-compute/`).
